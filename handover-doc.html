How to Maintain & Update the Website (Client Instructions)

1. Adding Legal Articles (Insights)

Open insights.html in cPanel File Manager Code Editor. Copy an existing <article class="insight-card"> block, update the title, publication date, author name, category tag, and summary. Save changes; the live site updates instantaneously.

2. Updating Team Profiles

Open people.html. To modify qualifications, designations, or bar admissions, locate the team member's <article class="team-profile-card"> and update the text. Upload any new portrait to assets/images/ as a square JPG.

3. Inquiries & Email Delivery

All client submissions from contact.html and careers.html are automatically formatted into executive HTML email briefs and routed to contact@colomboassociates.com. Ensure this inbox is monitored daily for timely client responses.

4. Routine Security Backups

Log into cPanel once per month, click on Backup Wizard, and download a Full or Partial Backup (Home Directory). Store this copy safely on an external hard drive or secure cloud storage.
